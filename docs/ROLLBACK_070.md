# Возврат к Auralis 0.7.0 — 29 октября 2026

По запросу владельца текущий проект возвращён к 0.7.0. Из активных исходников исключены изменения 0.7.1, 0.8.0 и 0.9.0. Сохранены исходные оформление, Black Hole, восемь сцен, локальный режим телефона, обложки, таймер сна и подборки версии 0.7.0.

## Готовые файлы

- Windows: `release/desktop/Auralis-0.7.0.exe`; `Auralis-Setup.exe` — тот же файл. Переносимая папка `release/desktop/Auralis` восстановлена из сохранённой 0.7.0.
- Android: `release/android/Auralis-Android-0.7.0-Preview.apk`, versionCode 12; `Auralis-Android-Test.apk` — тот же файл.
- SHA-256 обоих оригинальных установщиков совпадает с манифестом выпуска от 22 октября. [Манифест](../release/LOCAL_070_MANIFEST.json) · [Суммы](../release/SHA256SUMS-0.7.0.txt).

Установщики сохранены локально. В публичном GitHub Releases пока размещена прежняя 0.6.2; возврат исходников в main не загружает бинарные файлы в Releases автоматически.

## Проверено после возврата

- Чистая Java-сборка: 60 тестов без ошибок и пропусков — ядро 11, Desktop 31, сервер 18.
- Все 54 скомпилированных класса Desktop побайтно совпали с сохранённой поставкой 0.7.0.
- Исходные 52 мобильных входных файла восстановлены и сверены с сохранёнными SHA-256 старой сборки. После этого изменены только `package.json` и `package-lock.json`: исправлены ошибочные версии зависимостей старого lock-файла и закреплён XML-парсер 0.6.2 для воспроизводимой установки. Код приложения и графика остались прежними.
- `npm ci`, TypeScript, ESLint и все 19 тестов мобильной логики прошли.
- Сохранённая переносимая Windows 0.7.0 запущена с комплектным runtime и отдельной тестовой медиатекой: `AURALIS_UI_SMOKE_OK`.

Новый APK не пересобирался: возвращён оригинальный проверенный файл 0.7.0. Установка на физический телефон, iPhone и поверх пользовательской Windows-инсталляции в этом откате не выполнялась. Обычная установка Android APK с versionCode 12 поверх 13/14 запрещена системой; не удаляйте приложение с локальной музыкой без предварительного сохранения нужных данных.

Пользовательская музыка, базы и настройки на устройствах не изменялись. Отменённые исходники, более новые установщики и выходные каталоги сборки сохранены в локальном архиве `.runtime/rollback-to-070-…`; история GitHub сохранена отдельным коммитом возврата.
