# Auralis 0.9.0 — библиотека, которая остаётся с вами

Текущий интерфейс, палитры и восемь сцен графики сохранены. Новые возможности находятся в существующих настройках, очереди и меню треков. Для них не требуется аренда сервера.

## Резервная копия в один файл

1. На ПК откройте **Настройки → Резервная копия медиатеки**. На телефоне: **Настройки → Медиатека и резервная копия → Копия и восстановление**.
2. Выберите, включать ли музыку. В любом случае сохраняются обложки, метаданные, избранное, плейлисты, история, предпочтения и очередь. Данные входа и адреса серверов в копию не включаются.
3. Сохраните файл `.auralis` вне папки приложения. На телефоне используйте системное меню сохранения/отправки.
4. Для восстановления выберите файл, прочитайте предварительный просмотр и нажмите **Объединить** или **Заменить**.
5. Объединение сохраняет текущие метаданные совпавших треков. Отличающиеся плейлисты добавляются отдельно. Перед заменой на ПК создаётся `before-restore.auralis` в папке данных. На телефоне сначала сохраните собственную копию.

Архивы совместимы между ПК и телефоном. На телефоне один архив ограничен 3 ГБ, на ПК — 64 ГБ. Без включённого аудио на другом устройстве треки появятся как отсутствующие: добавьте оригиналы повторно, и связи восстановятся по содержимому файла. При проверке полного архива контролируются размеры, пути и SHA-256. Прерванная запись состояния телефона восстанавливается через журнал при следующем запуске.

## Удобная очередь

- В меню трека: **Следующим** или **В конец очереди**.
- В открытой очереди на ПК перетащите строку; с клавиатуры используйте **Alt + ↑ / ↓**, **Delete** и кнопку отмены.
- На телефоне удерживайте строку и двигайте её вверх/вниз. Есть отдельные кнопки для перемещения и удаления, доступные экранному диктору.
- Последние изменения можно отменять. Очередь сохраняется между запусками и восстанавливается на паузе.
- Кнопка сохранения создаёт плейлист. Повторы в очереди допустимы; в плейлист каждый трек включается один раз.

## Переходы и ровная громкость

В **Настройках → Переходы и громкость** задайте длительность crossfade от 0 до 12 секунд и исключения по альбомам. По умолчанию наложение выключено. На ПК включение непрерывного воспроизведения использует один PCM-выход 48 кГц / 16 бит, который не закрывается между треками. Первое декодирование файлов может потребовать времени; FFmpeg входит в Windows-поставку. На телефоне сохраняется нативная очередь системного плеера, а переходы выполняются нативным кодом, включая заблокированный экран.

Для выравнивания громкости:

1. Нажмите **Проанализировать локальные файлы**. Анализ читает реальное аудио; микрофон не используется.
2. Включите **Выравнивать воспринимаемую громкость**.
3. Выберите цель, например **−16 LUFS**. Тихие файлы не усиливаются сверх запаса до пика; тишина не усиливается.
4. Анализ можно остановить после текущего файла. Оригиналы не меняются.

ПК использует FFmpeg R128 с true peak. Телефон измеряет K-взвешенную интегральную громкость и sample peak; для усиления оставлен запас 2 дБ. Это разные виды измерения пика. Файлы без анализа играют с прежней громкостью.

## Метаданные и обложки

На ПК выделите треки через Ctrl/Shift и откройте **Метаданные и обложки**. На телефоне используйте меню трека или редактор в настройках. Доступны название, исполнитель, альбом, жанр, номер трека/диска, новая обложка и групповые изменения. Предварительный просмотр показывается до применения. По умолчанию меняется только библиотека.

На ПК есть отдельное действие **Записать теги в оригинал…**. Оно сначала создаёт рядом полную копию `имя.auralis-original-….bak`, затем записывает теги без перекодирования аудиодорожки. Новая обложка встраивается в MP3, FLAC и M4A; в остальных поддерживаемых контейнерах сохраняется прежняя встроенная обложка. Мобильный редактор сохраняет правки в библиотеке приложения.

## Прямой перенос между компьютером и телефоном

1. Подключите оба устройства к одной обычной Wi-Fi-сети. Гостевая сеть с изоляцией клиентов может блокировать обмен.
2. На ПК откройте **Настройки → Мои устройства → Подключить телефон**.
3. Выберите локальный адрес компьютера и нажмите **Начать сеанс**. При запросе Windows разрешите Auralis доступ в вашей частной сети.
4. На телефоне в локальном режиме откройте **Настройки → Мои устройства · Wi-Fi**. Отсканируйте QR; доступ к камере запрашивается только здесь. Можно вставить код вручную.
5. Сравните шестизначный код на двух устройствах и подтвердите телефон на ПК.
6. Для отправки с ПК отметьте треки/плейлисты и нажмите **Подготовить выбранное для телефона**, затем **Получить выбранное с компьютера** на телефоне.
7. Для обратного направления отметьте музыку на телефоне и нажмите **Отправить выбранное**.
8. На принимающем устройстве прочитайте предварительный просмотр. Только после подтверждения данные добавятся в библиотеку.

Передача идёт по HTTPS с проверкой сертификата из QR. Каждый сеанс получает новый ключ и закрывается через 15 минут или при закрытии окна обмена. Это локальный перенос: подключение из другой сети через интернет и постоянная автоматическая синхронизация требуют отдельного серверного режима, который сохранён. Код подключения предназначен для вашего второго устройства.

## Автоматическое качество графики

В настройках графики появился переключатель **Автокачество**. При длительных тяжёлых кадрах сначала снижается разрешение и число фоновых частиц, затем доступный FPS. На телефоне также учитываются энергосбережение и состояние нагрева. Восстановление качества происходит с задержкой, чтобы режим не переключался туда-сюда. Любимая сцена, её цвета, скорость и характер вспышек сохраняются.

Отключите автокачество, если нужно фиксированное качество. Для постоянного рендера Black Hole в 3840 × 2160 на ПК включите 4K и отключите автокачество. Сворачивание останавливает графику. Системное уменьшение движения учитывается автоматически; ручные переключатели анимаций и эффектов остаются.

## Виджет и доступность

На главном экране телефона удерживайте свободное место → **Виджеты → Auralis · музыка**. Виджет показывает трек и кнопки «Назад», «Играть/Пауза», «Далее». Нажатие открывает плеер и выполняет команду; это работает и после закрытия приложения. Для фонового управления без открытия приложения остаются системные элементы на экране блокировки/в уведомлении.

Кнопки получили подписи для экранных дикторов, очередь — альтернативы перетаскиванию. Основной текст и подписи акцентных кнопок проверяются на контраст 4,5:1 во всех существующих палитрах. Общие клавиши ПК: **Пробел**, **← / →** для перехода на 5 секунд и **F11**.

## Установка и сборка

Windows: запустите `release/desktop/Auralis-0.9.0.exe` либо `release/desktop/Auralis/Auralis.exe`. Перед обновлением старой 0.1 используйте `release/desktop/Safe-Update.ps1`, как описано в руководстве обновления. Обычные данные хранятся в `%LOCALAPPDATA%\AuralisData`.

Android: `release/android/Auralis-Android-0.9.0-Preview.apk`, ARM64. Установите поверх предыдущей Preview с той же подписью. Удалять приложение и терять локальную музыку для обновления не требуется. Если подписи отличаются, сначала сделайте копию библиотеки. Это тестовая сборка; для магазина используйте собственную постоянную подпись.

Сборка из корня проекта:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-25.0.3'
$env:Path = "$env:JAVA_HOME\bin;C:\maven\bin;$env:Path"
mvn -B verify
.\scripts\build-desktop.ps1 -Type exe -SkipTests
cd apps/mobile
npm ci
npm run typecheck
npm run lint
npm test
npm exec -- expo run:android --variant release
```

Linux: `bash scripts/build-linux.sh deb` на Linux с JDK 25, Maven, FFmpeg и пакетными инструментами. iOS: исходники и виджет включены в проект; профиль EAS/App Store и требования к подписи описаны в [руководстве магазинов](RELEASE_GUIDE.md). Проверка iOS в GitHub Actions собирает симулятор без Apple-ключей; она не создаёт IPA для установки на iPhone. Проверка на физических устройствах отмечается отдельно в отчёте, а не подменяется результатом сборки.
