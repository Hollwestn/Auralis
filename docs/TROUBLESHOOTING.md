# Устранение неполадок

| Проблема | Проверка | Решение |
|---|---|---|
| Окно не открылось | Запустите `scripts/run-desktop.ps1`, прочитайте stderr | JDK25, зависимости JavaFX, полный комплект app/runtime/lib |
| Невозможно импортировать | В статусе и диалоге есть причина FFprobe | Проверьте файл через `ffprobe -v error -show_format "путь"`; защищённые/повреждённые файлы не поддерживаются |
| Нет звука | Растёт ли таймер, громкость Auralis и Windows | Выберите рабочее устройство вывода; проверьте PCM WAV; аппаратный вывод отдельно не тестировался |
| FLAC начинает играть с задержкой | Создаётся WAV кэша | Дождитесь декодирования, проверьте место; повторный запуск использует копию |
| FFmpeg не найден | `scripts/check-system.ps1` | Установите FFmpeg/FFprobe или используйте полный установщик с app/tools; переменные AURALIS_FFMPEG/AURALIS_FFPROBE задают абсолютный путь |
| Трек исчез с диска | Исходный путь в «Сведения об аудио» | Верните файл/пересканируйте папку; SQLite не хранит оригиналы |
| Волна пустая | Есть ли импортированные треки и разрешённые исполнители | Добавьте музыку; Favorites требует любимых; исключения и дизлайки исключают кандидатов |
| Рекомендации однообразны | Размер каталога и реальные genre/artist теги | Заполните теги, предпочтения и оценки; алгоритм не получает новую музыку из внешних сервисов |
| Экспорт не работает | Ошибка FFmpeg и длительности clips | Исправьте диапазон, уменьшите crossfade/fades, проверьте исходники и права на новую папку |
| «Не перезаписывать исходник» | Имя экспорта совпадает с исходным clip | Выберите новое имя файла |
| Сервер недоступен | `/api/v1/health`, серверный лог, firewall, порт | Запустите сервер, задайте адрес. На телефоне localhost указывает на телефон, используйте IP ПК или HTTPS домен |
| HTTP401 | Сессия истекла/перезапуск сервера/выход | Войдите заново; токен Desktop не сохраняется |
| HTTP409 при sync | Другой клиент изменил версию | Повторно загрузите состояние и осознанно отправьте свою версию |
| HTTP404 трека другого пользователя | Трек принадлежит другому аккаунту | Используйте единый аккаунт, явно импортируйте музыку в его каталог |
| Мобильный фон не работает в Expo Go | Нативные audio permissions не входят в Go | Соберите development/release APK, включите системное уведомление; проверьте на устройстве |
| Нет APK в release | Android SDK не установлен/сборка не запускалась | Выполните Android guide; файл не создаётся фиктивно |

Не удаляйте SQLite/музыку для устранения ошибки без резервной копии. Для сообщения об ошибке приложите версию, шаги и текст сообщения; пароли и bearer tokens не включайте.
