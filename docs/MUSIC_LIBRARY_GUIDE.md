# Музыкальная библиотека

1. Нажмите «+ Добавить музыку» для файлов или «Папка» в медиатеке. Можно перетащить файлы/папку в окно.
2. Дождитесь статуса «Добавлено… дубликатов… ошибок…». Сканирование рекурсивное; неподдерживаемые или повреждённые файлы показываются в ошибках. Во время анализа окно остаётся доступным.
3. Треки содержат реальные теги. При отсутствии artist/album используются подписи «Неизвестный исполнитель» / «Без альбома», а не выдуманные данные. Для обложки нужен embedded artwork.
4. Ищите по названию, исполнителю, альбому, жанру. Заголовки таблицы позволяют сортировать. Двойной щелчок начинает воспроизведение с выбранного трека.
5. Контекстное меню → «В любимое», «В очередь», «В плейлист». Создайте плейлист кнопкой «+» слева. Внутри плейлиста строки можно перетаскивать для изменения порядка.
6. «Переименовать», «Обложка», «Экспорт M3U8», «Удалить» доступны на странице плейлиста. Удаление плейлиста не удаляет аудио.
7. Настройки → «Импорт M3U8» читает пути к существующим локальным файлам. Сетевые URL плейлиста не скачиваются. Для переноса на другой ПК нужно перенести сами аудиофайлы и сохранить/поправить пути.
8. После добавления файлов в ранее выбранную папку: Настройки → «Пересканировать». Постоянного filesystem watcher в этой версии нет.

FLAC/OGG/OPUS и другие форматы при необходимости конвертируются в кэш WAV перед первым воспроизведением. Это занимает время и место. Если FFmpeg отсутствует, установите его/проверьте комплект `app/tools`. Удалённый исходник не восстанавливается автоматически из SQLite.

«История» содержит действительные сеансы прослушивания, а не просто клики по строкам. Избранное и настройки сохраняются после закрытия. Для синхронизации с телефоном нужна явная серверная копия — обычный локальный файл на телефоне недоступен.
