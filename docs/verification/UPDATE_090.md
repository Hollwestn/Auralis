# Проверка Auralis 0.9.0 — 29 октября 2026

Дизайн, палитры, исходник общего GLSL-шейдера и модель Black Hole сохранены. Новые действия встроены в существующие меню, настройки и очередь. [Руководство](../UPDATE_090.md).

## Что проверено

- `mvn -B verify`: **79 тестов**, 0 ошибок, 0 пропусков: ядро 19, Desktop 42, сервер 18.
- `npm run typecheck`, `npm run lint`: успешно. Мобильная логика: **34 теста**, 0 ошибок, 0 пропусков.
- Android: **6 нативных тестов** PCM/FFT/громкости. Проверены пустые буферы, реальный спектр синуса, sample gain, ограничение отсчётов, float stereo и эталонная громкость mono/stereo.
- Реальный PCM-выход Windows: воспроизведение, пауза, перемотка, редактирование очереди. Отдельно проверен точный суммарный размер PCM на границах gapless/crossfade и один выходной поток.
- На видеокарте NVIDIA RTX 3050: восемь непустых GPU-сцен, реакция на синтетический аудиосигнал, восемь палитр, медленное движение в паузе, отсутствие эффекта нажатия, 3840 × 2160, снижение движения, остановка при сворачивании и выключенных эффектах.
- Сценарии Desktop: **55 проверок интерфейса**, включая библиотеку, поиск, избранное, плейлисты, волну, эквалайзер, аудиостудию, отмену и удаление без удаления оригиналов.
- Архив мобильного кода восстановлен в Java-приложении, затем созданный Java архив проверен и распакован мобильным кодом. Аудио, контрольные суммы, настройки, плейлист и избранное совпали.
- Локальный HTTPS-транспорт: секрет, подтверждение устройства, запрет чужого устройства, сертификат из QR, скачивание и загрузка архива. Неподтверждённая передача не импортируется автоматически.
- APK содержит нативные методы очереди, громкости, обмена и атомарного сохранения, расширение спектра, графику и виджет. Подпись APK v2 и выравнивание 16 КБ проверены. Сертификат совпадает с Preview 0.8.0.
- Установщик и переносимая папка Windows собраны; запуск приложения из поставки с отдельной тестовой библиотекой прошёл.
- Linux: DEB собран, установлен и запущен в Ubuntu 24.04 x86_64. [Проверка](https://github.com/Hollwestn/Auralis/actions/runs/40854758108), [артефакт](https://github.com/Hollwestn/Auralis/actions/runs/40854758108/artifacts/12888448766).
- iOS: приложение и расширение виджета **успешно скомпилированы** Xcode 26.2 / Swift 6.2 для ARM64-симулятора без Apple-ключей. [Проверка](https://github.com/Hollwestn/Auralis/actions/runs/40823296021). После этого изменения общих экранов прошли актуальные typecheck/lint/34 теста и отдельную сборку Hermes для iOS.

## Пределы проверки

Физические Android и iPhone сейчас не подключены. Установка этого APK на телефон, реальное сопряжение двух устройств по Wi-Fi, команды системного виджета на устройстве и оценка переходов на слух остаются аппаратной проверкой. Сборка и программные тесты не заменяют её.

Сборка iOS-симулятора не является IPA для iPhone. Подписание, App Groups, TestFlight и публикация выполняются владельцем Apple-аккаунта по [руководству](../RELEASE_GUIDE.md). Магазинный AAB с постоянным ключом также собирается отдельно от тестового APK.

На телефоне измеряется sample peak с запасом 2 дБ, на ПК — true peak через FFmpeg. Эти измерения не отождествляются. Новые обложки при записи оригиналов встраиваются в MP3/FLAC/M4A; в остальных поддерживаемых контейнерах прежняя встроенная обложка сохраняется. В мобильном редакторе изменения хранятся в библиотеке.

Локальные подробные логи находятся в `.runtime/090-verify-final.log`, `090-mobile-tests.log`, `090-android-final.log`, `090-archive-interop.log`, `090-visual-checked.log`, `090-flow-checked.log` и `desktop-090-portable.log`. Они не включаются в публичные исходники.
