# Auralis на iPhone и iPad

Исходники мобильного клиента общие с Android: `apps/mobile`. Нативный проект генерируется командой Expo prebuild; в скачанном репозитории папки `ios` может не быть. Локальная компиляция Swift/CocoaPods и Xcode требуют macOS. С Windows можно заказать облачную сборку через EAS, однако подпись и правила распространения Apple всё равно действуют. Платный музыкальный сервер для локальной библиотеки не нужен.

## Установить себе без платной подписки Apple

Нужен доступ к Mac с Xcode и ваш Apple Account. Выполните шаги «Сборка на Mac» ниже, в Signing & Capabilities выберите Personal Team и запустите Release на подключённом iPhone. Обычный APK на iPhone не устанавливается.

Бесплатная Personal Team предназначена для личного тестирования: профиль действует 7 дней, затем приложение нужно пересобрать и установить заново. Это не общедоступная ссылка на установку для друзей. Ограничения описаны в [официальной справке Apple](https://developer.apple.com/help/account/basics/about-your-developer-account).

## Облачная сборка из Windows и установка через TestFlight

В `apps/mobile/eas.json` подготовлены профили `ios-simulator` и `ios-testflight`. Владелец должен связать проект со своим Expo-аккаунтом и выбрать уникальный Bundle Identifier в `app.config.ts` (текущий `io.auralis.mobile` — значение проекта, доступность в аккаунте Apple не проверена).

```powershell
cd apps/mobile
npm ci
npm run typecheck
npm run lint
npm test
npx eas-cli@latest login
npx eas-cli@latest build:configure
npx eas-cli@latest build --platform ios --profile ios-testflight
npx eas-cli@latest submit --platform ios --profile production
```

При первой настройке разрешите EAS создать/привязать проект и настроить подпись своим Apple Developer-аккаунтом. Не передавайте пароль, коды и сертификаты в переписке. Проверьте, что `AURALIS_ALLOW_HTTP` не задан для распространения; локальное прослушивание не требует HTTP.

После успешной сборки и загрузки: App Store Connect → ваше приложение → TestFlight → дождаться обработки → заполнить сведения о тестировании → добавить тестировщиков. Для внешних тестировщиков может понадобиться Beta App Review. На iPhone установить TestFlight, принять приглашение и скачать Auralis. Обычная публикация в App Store дополнительно требует оформления страницы, сведений о приватности и App Review.

Для TestFlight/App Store нужна Apple Developer Program, обычно **99 USD в год** или местная цена. Сборка EAS выполняется по доступным лимитам вашего тарифа; бесплатная очередь не означает бесплатную подпись Apple. [Expo: настройка сборки](https://docs.expo.dev/build/setup/), [Apple: регистрация](https://developer.apple.com/programs/enroll/).

Для проверки компиляции под симулятор без Apple Developer Program:

```powershell
npx eas-cli@latest build --platform ios --profile ios-simulator
```

Результат этого профиля запускается в iOS Simulator на Mac и **не устанавливается на физический iPhone**. См. [документацию Expo](https://docs.expo.dev/build-reference/simulators/).

## Статус текущей версии

В 0.7.0 предусмотрены iOS-реализации чтения встроенных обложек через AVFoundation/ImageIO и нативного таймера сна. Это исходники для проверки на Mac; экспорт JavaScript-бандла не доказывает компиляцию Swift, работу аудиотапа, подпись или установку на iPhone. В данном Windows-окружении IPA не собиралась и совместимость на реальном iPhone не подтверждалась.

## Сборка на Mac

1. Установите [Xcode](https://developer.apple.com/xcode/) и его Command Line Tools. Откройте Xcode один раз и завершите установку компонентов.
2. Установите Node.js 24 и CocoaPods. Скопируйте весь репозиторий на Mac; не переносите Windows-папку `node_modules`.
3. В терминале Mac выполните:

   ```sh
   cd Auralis/apps/mobile
   npm ci
   npm run typecheck
   npm run lint
   npm test
   npx expo prebuild --platform ios --no-clean
   cd ios
   pod install
   open Auralis.xcworkspace
   ```

   `npm ci` автоматически применяет проверяемое расширение нативного аудио, включая MTAudioProcessingTap для настоящего спектра AVQueuePlayer. В package.json задано `expo.autolinking.ios.buildFromSource: ["expo-audio"]`: CocoaPods должен собирать изменённый модуль из Swift/ObjC, а не скачивать готовый XCFramework без расширения. Не удаляйте этот параметр и postinstall. При обновлении Expo Audio нужно пересмотреть расширение, а не отключать проверку его версии.
4. В Xcode выберите target Auralis → Signing & Capabilities → свою Team и уникальный Bundle Identifier. Подключите iPhone, разрешите доверие и включите Developer Mode, если iOS этого требует.
5. Выберите устройство и выполните Run. Для самостоятельной работы без Metro используйте Release-конфигурацию или Archive; обычная Debug-сессия разработчика может обращаться к Metro.
6. Для симулятора выполните `npm run ios`. Для физического устройства можно использовать `npx expo run:ios --device` после настройки подписи.

В проекте включён `UIBackgroundModes: audio`, а управление экраном блокировки обслуживает нативный AudioPlaylist. Разрешение микрофона и фоновая запись не нужны. При первом подключении к локальному серверу iOS может запросить доступ к локальной сети — разрешите его для своего сервера.

## Сервер, библиотека и офлайн

Укажите базовый HTTPS-адрес сервера без `/api/v1`. Войдите в общий аккаунт. Добавьте музыку на сервер с Desktop с явным согласием на загрузку. Треки можно скачать через меню и воспроизводить из «Моя музыка → Скачано» без сети. Токен хранится в iOS Keychain с привязкой к устройству; пароли в файлы приложения не записываются.

Для локальной музыки после заставки выберите «Продолжить без аккаунта» → «Добавить музыку с телефона» и выберите файлы через системный экран Files. Импорт копирует файлы во внутреннее хранилище; музыка и её обложки остаются доступны без музыкального сервера. Таймер сна доступен в плеере, подборки — в «Моей музыке».

Для временной проверки частного HTTP-сервера перед prebuild можно задать `AURALIS_ALLOW_HTTP=1`. Это отдельная конфигурация разработки. Серверный режим сборки для распространения должен использовать HTTPS и выполняться без этой переменной.

Проверьте потоковое воспроизведение, перемотку, очередь, скачивание, лайки, плейлисты, историю, «Мою волну», продолжение с ПК, воспроизведение после блокировки экрана и Bluetooth. Восемь GLSL-режимов и нативный аудиотап дополнительно проверяются на реальном устройстве. Поддержка FLAC/OGG и других контейнеров зависит от системного декодера iOS; при несовместимости создайте поддерживаемую копию в Desktop, сохранив оригинал.

## TestFlight и App Store

Для TestFlight/App Store нужны Apple Developer Program, собственный Bundle Identifier, сертификаты/профили и запись приложения в App Store Connect. В Xcode выберите Product → Archive → Distribute App → App Store Connect. Заполните данные приложения и приватности, загрузите сборку и дождитесь обработки. Разрешение тестировщикам и публикация выполняются владельцем аккаунта. В этом окружении учётная запись Apple, подпись и загрузка в App Store Connect не выполнялись.

Личный бесплатный Apple ID может позволять локальный запуск через Xcode с ограничениями Apple; это не общедоступная установка без подписи. Готовый IPA и успешная установка на iPhone не заявляются без фактической сборки и проверки. См. `MOBILE_TEST_REPORT.md`.
