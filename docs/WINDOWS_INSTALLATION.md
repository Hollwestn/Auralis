# Установка Auralis на Windows

Готовая сборка рассчитана на Windows x64. Для ручной установки также доступен `release/desktop/Auralis-0.6.1.msi`.

## Обновление ранее установленной версии 0.1

1. Закройте все окна старого Auralis. Сохраните копию своих музыкальных папок.
2. В новой папке проекта откройте PowerShell и выполните `./release/desktop/Safe-Update.ps1`. Рядом должны находиться новый установщик и полная portable-папка `Auralis`.
3. Скрипт запускает перенос без интерфейса, проверяет результат, создаёт резервную копию в `%LOCALAPPDATA%\AuralisBackups\дата-время`, затем открывает мастер обновления. При ошибке установщик не запускается.
4. Новая программа устанавливается по умолчанию в `%LOCALAPPDATA%\AuralisApp`, данные находятся отдельно в `%LOCALAPPDATA%\AuralisData`. Папку данных не выбирайте в качестве папки установки.
5. Если запуск PowerShell заблокирован политикой, откройте новую portable-версию `release/desktop/Auralis/Auralis.exe`: она перенесёт старую медиатеку до открытия окна. Проверьте коллекцию, закройте программу, затем запустите `Auralis-Setup.exe`. Глобальную ExecutionPolicy менять не нужно.

Переход 0.1→0.2 проверяется установщиком: при обнаружении старой `Auralis/library.db` без подготовленной `AuralisData/library.db` установка останавливается до удаления старой программы. Это предотвращает потерю медиатеки из-за прежнего совпадения папок установки и данных. Старые файлы сохраняются до запуска обновления; внешний музыкальный оригинал не перемещается. Подробности и восстановление — `DATA_MIGRATION.md`.
## Готовая сборка

1. Откройте `release/desktop/Auralis-Setup.exe` из папки проекта. Если файла нет, выполните сборку ниже; пустой EXE вместо установщика не создаётся.
2. Выберите пользовательскую папку установки и дождитесь завершения. Отдельный JDK для готовой сборки не нужен: jpackage включает runtime.
3. Откройте Auralis из меню «Пуск» или ярлыка. Ожидается окно с мастером первого запуска.
4. По умолчанию выбрана Obsidian Yellow. В настройках доступны восемь тем, включая сохранённые Jade, Amber и Azure. В локальном режиме аккаунт не нужен.
5. Нажмите «Добавить папку» или завершите мастер и используйте «+ Добавить музыку». Дождитесь окончания фонового сканирования.
6. Откройте «Медиатека», дважды нажмите на трек. Кнопка плеера меняется на паузу, таймер растёт.

Сборка не подписана цифровым сертификатом. Установщик не подписан коммерческим сертификатом. Проверка установки выполняется только в отдельную тестовую папку при отсутствии ранее установленного Auralis. Фактическая проверка install/uninstall на чистой Windows описывается в `TEST_REPORT.md`; если её там нет, она не проведена.

## Данные

SQLite и обложки: `%LOCALAPPDATA%\AuralisData`. Ваши оригинальные аудиофайлы остаются в выбранных папках. Приложение не отправляет их на сервер автоматически. Не перемещайте исходники без пересканирования. Для резервной копии закройте приложение, скопируйте папку Auralis и отдельно музыкальные папки.

## Обновление и удаление

Закройте Auralis, сделайте резервную копию данных, запустите новый установщик с тем же upgrade UUID. Проверяйте заметки к версии и миграции. Удаление: Windows → Параметры → Приложения → Установленные приложения → Auralis → Удалить. Личная папка данных должна сохраняться; удалять её можно вручную после резервной копии. В 0.1 автоматическое обновление не реализовано.

## Сборка из исходников

Установите JDK 25, Maven 3.9+, FFmpeg/FFprobe, WiX Toolset 3.11+ (bin в PATH). В PowerShell из корня проекта:

```powershell
.\scripts\check-system.ps1
.\scripts\build-desktop.ps1 -Type exe
```

Ожидаемый результат: `release/desktop/Auralis-Setup.exe`. Скрипт останавливается при ошибке Maven/jpackage. При отсутствии WiX можно собрать portable каталог: `build-desktop.ps1 -Type app-image`; запуск — `release/desktop/Auralis/Auralis.exe`.

Для запуска исходников: `scripts/run-desktop.ps1`. После смены JDK откройте новую PowerShell и проверьте `java -version`.

## Визуализации

После запуска музыки откройте главную страницу и список «Атмосфера». В «Настройках» доступны восемь тем, восемь режимов, качество, FPS, интенсивность, отключение фона и всех анимаций. Начните с MEDIUM/45 FPS/90%, на слабом ПК — LOW/30 FPS. Пошаговая инструкция и действия при отсутствии 3D: docs/VISUALIZATIONS_GUIDE.md.
