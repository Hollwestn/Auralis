# Скорость графики и новая иконка — 0.6.1

В Windows откройте «Настройки» → «Графика звука». На телефоне откройте полноэкранную визуализацию и прокрутите к её параметрам либо найдите их в настройках. Доступны два независимых ползунка:

- **Скорость без музыки**: по умолчанию **100%**. Это прежняя спокойная скорость: часы сцены идут с множителем 0,18.
- **Скорость при воспроизведении**: по умолчанию **75%**, на четверть медленнее прежней.

Диапазон каждого ползунка — 0–200%. Ноль останавливает движение геометрии соответствующего состояния. Кнопка «Сбросить скорость» возвращает 100% и 75%. Отдельное отключение анимаций и режим уменьшенного движения имеют приоритет над скоростью.

Параметры сохраняются между запусками и передаются через синхронизацию одного аккаунта. Для старых настроек без этих полей применяются новые значения по умолчанию. Управление меняет часы сцены; анализ реального аудио и характер музыкальных вспышек сохранены.

Одобренная модель Black Hole, её размер, палитры и звуковая реакция сохранены. Новая иконка взята из предоставленного `auralis-symbol.zip`: исходные ICO/PNG скопированы без перерисовки. Она применена к Windows EXE/установщикам/окну и интерфейсу, Android launcher/splash и мобильному интерфейсу. Для iOS подготовлены ресурсы, нативная сборка требует Mac.
