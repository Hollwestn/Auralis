# Актуальный мобильный выпуск 0.6.2

Добавлен самостоятельный режим без сервера и регистрации: вход «Продолжить без аккаунта», системный выбор файлов, постоянные внутренние копии, локальные плейлисты, избранное, история, поиск и волна. Исходники не отправляют локальные треки на сервер.

Проверено: TypeScript, ESLint, 17 Node-тестов, 3 нативных PCM-теста, Android/iOS Hermes export, сборка настоящего APK 0.6.2 / code11, подпись v2 и 16KiB alignment. Сверены 36 входных файлов и 11 файлов source map готового APK. APK установлен на S21; в сохранённом UI-снимке виден новый вход без аккаунта.

Полный сценарий локального импорта/воспроизведения на физическом телефоне **не завершён**: проверка разрешений диагностической команды остановлена лимитом использования. Это ограничение проверки, а не подтверждение работоспособности всего нового режима. Его следует проверить перед стабильным выпуском. [Инструкция](MOBILE_OFFLINE_GUIDE.md).

Windows остаётся на 0.6.1. Далее сохранён предыдущий отчёт: его результаты нативного телефона относятся к серверному режиму 0.6.1, не к новой локальной библиотеке 0.6.2.

# Мобильная проверка 0.6.1 — 19.10.2026

Собран автономный release APK **0.6.1 / code10**, arm64-v8a, Android7+ (API24), targetSDK36. Metro/Expo Go не нужны. Подпись тестовая, прежний сертификат сохранён. [Данные APK](verification/android-apk.json), [сводный отчёт](../TEST_REPORT.md).

## Настоящий телефон

На Samsung Galaxy S21 **SM-G991B, Android 15** установлен финальный APK поверх предыдущего. Проверены заставка и запуск, вход на изолированный тестовый сервер, настоящий серверный WAV через ExoPlayer, пауза и восемь GPU-сцен: Black Hole, Nebula Drift, Resonance, Photon Tunnel, Prism Bloom, Magnetic Field, Ocean Caustics, Fractal Cathedral. Сцены отрисовываются без сообщения о недоступности GPU; сохранены снимки и измерения пикселей.

Оба нативных ползунка меняются независимо и сохраняются сервером; сброс возвращает 100% / 75%. Для проверки PCM оба временно установлены в 0: неподвижная Black Hole во время воспроизведения меняет яркость вспышек. Среднее отличие RGB от паузы в восьми кадрах составляет 0,60–5,58; движение геометрии в этой проверке исключено. MediaSession показывает PLAYING(3), error=null. Прежней ошибки пустого буфера нет. Тестовый аккаунт удалён, скорости восстановлены, на телефоне оставлен вход.

[Проверка устройства](verification/android-device.json), [8 сцен](verification/android-device-modes.json), [PCM-вспышки](verification/android-device-audio.json), [причины исправления](ANDROID_STARTUP_FIX.md).

## Автоматические проверки

ESLint, TypeScript, 12 Node-тестов, 3 нативных PCM-теста и экспорты Hermes Android/iOS прошли. Проверены 35 входных файлов и 12 файлов source map настоящего APK; тело HBC совпало с независимым экспортом. В DEX присутствуют публичные исполняемые JNI flush() и конструктор GLView. Предыдущая матрица 48 вариантов шейдеров / 64 палитр применима: сам шейдер не менялся.

В React Native Web / Edge (390×844) проходят 10 UI-проверок с настоящим отдельным backend: заставка/вход, главная, музыка, поиск, плейлист, темы, sync, скорость. Ошибок страницы нет. Эти браузерные проверки дополняют нативную проверку, детали транспорта различаются.

A55 отдельно не проверен; Bluetooth, длительный фон и расход батареи не измерены. Нативная iOS IPA на Windows не собрана. [Android установка](ANDROID_INSTALLATION.md), [iOS сборка](IOS_INSTALLATION.md), [сервер через интернет](SERVER_INTERNET_GUIDE.md).
