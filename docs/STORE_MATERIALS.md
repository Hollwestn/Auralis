# Материалы для карточек Auralis 0.8.0

Поддержка: **auralishelp@mail.ru**. Сначала прочтите [гайд](RELEASE_GUIDE.md). Это заготовки карточек и инвентаризация данных, а не автоматически заполненные анкеты магазинов.

## Название и тексты

Название: **Auralis**

Кратко: **Ваша музыка, живая графика звука и личная медиатека без регистрации.**

Полное описание:

> Ваша музыка. Ваше пространство.
>
> Auralis объединяет личную музыкальную коллекцию и графику, которая реагирует на звучание собственного плеера. Импортируйте аудиофайлы с устройства, собирайте плейлисты, сохраняйте любимое и открывайте свою волну на основе вашей библиотеки.
>
> Начните без регистрации и сервера: музыка остаётся в локальной библиотеке. При желании подключите собственный сервер Auralis для доступа к своей коллекции и синхронизации поддерживаемых данных между устройствами.
>
> Выберите цветовую тему, настройте графику и её скорость во время музыки и в паузе. Для спокойного прослушивания эффекты можно уменьшить или отключить. Фоновое воспроизведение и управление с экрана блокировки помогают продолжать слушать вне приложения.
>
> Auralis не предоставляет коммерческий музыкальный каталог. Для воспроизведения нужны ваши аудиофайлы или доступ к настроенному вами серверу. Доступность форматов зависит от платформы и системных кодеков.

Ключевые слова для Apple (проверьте лимит в консоли): `музыка,плеер,офлайн,плейлисты,визуализация,аудио,медиатека`

Английское краткое описание: **Your music, reactive visuals, and a personal library. No account required.**

## Скриншоты и графика

- Используйте текущую иконку `apps/mobile/assets/auralis-icon.png`; не меняйте символ бренда. Для iOS подготовлен непрозрачный RGB-экспорт `apps/mobile/assets/auralis-icon-ios.png` 1024×1024 с тем же символом. Повторная генерация: `node scripts/generate-store-icons.cjs` из `apps/mobile`. Проверьте требования выбранного магазина к размерам.
- Снимите реальные экраны: вход без аккаунта, библиотека с собственными треками, плеер, графика звука, плейлисты и темы. Без фиктивных отзывов, рейтингов и обещаний каталога.
- Для Google Play подготовьте отдельно feature graphic по размеру, указанному консолью; для Apple — скриншоты требуемых классов iPhone/iPad. Не выдавайте Desktop-скриншот за мобильный.
- Используйте музыку и обложки, на публикацию которых у вас есть права. В сборке нет набора коммерческих треков.

## Заметки проверяющему (можно перевести на язык анкеты)

Основные функции доступны без аккаунта и музыкального сервера. На экране входа выберите «Продолжить без аккаунта», затем импортируйте разрешённый аудиофайл через системный выбор файлов. Откройте трек, плейлист и настройки графики. Графика анализирует аудио плеера; микрофон не используется. Аккаунт создаётся только на необязательном сервере, указанном самим пользователем. Для проверки этой части владелец должен предоставить работающий HTTPS-сервер и отдельный тестовый аккаунт в закрытых заметках консоли, а не в публичном репозитории. Удаление доступно: Настройки → Удалить аккаунт и его данные.

## Данные: основа для Data safety / App Privacy

| Данные | Где и зачем | Что проверить при публикации |
|---|---|---|
| Локальные треки, обложки, библиотека, история, избранное | В хранилище устройства для выбранных функций | Системное резервное копирование и его настройки; это не отправка разработчику |
| Email, имя, данные авторизации | При регистрации/входе на выбранном сервере | Сервер получает их; не выбирайте автоматически «данные не собираются» для всего приложения |
| Токен сессии | SecureStore на телефоне, в заголовках запросов к серверу | Не публиковать и не добавлять в диагностические отчёты |
| Запросы, история, предпочтения, синхронизация | На подключённом пользователем сервере | Цели: функции приложения и синхронизация; выяснить политику оператора и резервных копий |
| Письма в поддержку | Email отправителя и то, что он сам написал | Не просить пароли и личные треки; обработка только для ответа |
| Рекламные идентификаторы/микрофон | Приложение не запрашивает и не использует | Повторить аудит SDK и итогового Android manifest / Xcode archive при добавлении зависимостей |

В версии нет собственных рекламных или аналитических SDK. Нельзя считать это достаточным для ответа «ничего не собираем»: правила Google и Apple учитывают конкретные сетевые функции и SDK. Разработчик заполняет обязательные категории, связь с пользователем, передачу третьим лицам и цели по фактическому поведению финального бинарника. Политика не устанавливает сроки хранения для чужих серверов; администратор каждого сервера отвечает за свои данные и резервные копии.

Удаление аккаунта выполняет серверный API и требует доступного сервера. При утрате входа пользователь связывается с администратором своего сервера. Поддержка Auralis помогает с процедурой, но не имеет доступа к произвольному частному серверу и не может обещать удалить данные на нём самостоятельно. Перед релизом проверить сценарий на доступном тестовом сервере и соблюдение требований магазина к внешнему запросу удаления.

Ссылки: [Data safety Google](https://support.google.com/googleplay/android-developer/answer/10787469), [удаление аккаунта Google](https://support.google.com/googleplay/android-developer/answer/13327111), [App Review](https://developer.apple.com/app-store/review/guidelines/), [privacy manifest Expo](https://docs.expo.dev/guides/apple-privacy/).
