# Графическая система Auralis 0.6.0

Desktop и Mobile исполняют один процедурный фрагментный шейдер: `shared/visuals/cinematic.frag`. Старые JavaFX сферы/торусы и имитация линзирования дугой заменены. Видеозаписи и готовые картинки вместо аудиореактивной сцены не используются.

## Рендер и потоки

Desktop: LWJGL3.4.3 / GLFW / OpenGL3.3, скрытый контекст, framebuffer. Один выделенный daemon-поток выполняет компиляцию, GLSL, чтение пикселей и загрузку текстуры обложки. JavaFX только копирует завершённый кадр в ImageView. Контекст общий для приложения; framebuffer/текстуры отдельны для панелей. У каждой панели допускаются один выполняющийся кадр и один последний ожидающий запрос, поэтому медленная GPU не создаёт растущую очередь. Смена режима на паузе также сохраняет последний выбор.

Mobile: Expo58 GLView / OpenGL ES, тот же GLSL100-совместимый алгоритм. Модуль `cinematic.generated.ts` генерируется из общего файла; `node scripts/sync-visuals.mjs --check` проверяет точное совпадение. На Desktop Maven включает исходный `.frag` в JAR без генерации.

## Сцены

| Режим | Визуальная механика |
|---|---|
| Black Hole | Одобренная объёмная сцена; тихое вращение без музыки, прежняя скорость с музыкой и вспышки |
| Nebula Drift | Объёмные облака и подсвеченные просветы туманности |
| Resonance | Узловые линии стоячих волн и зернистый свет |
| Photon Tunnel | Световые рамки с перспективой и движением в глубину |
| Prism Bloom | Гранёный кристалл, внутренние оптические узоры и блики |
| Magnetic Field | Дипольные силовые линии с движущимся светом |
| Ocean Caustics | Два слоя деформируемых световых каустик |
| Fractal Cathedral | Пространственная повторяющаяся гиройдная структура |

В0.6.0 Black Hole заново построен по видеореференсу как3D-объём. Размеры карточек510/490px и расположение сцены сохранены. Desktop допускает отдельный framebuffer3840×2160, с компенсацией пропорций окна черезu_aspect; по умолчанию используется обычное разрешение. Mobile сохраняет адаптивные пределы400/640/900px. Видео в сцене не используется. В 0.6.0 остальные семь режимов полностью заменены: [описание и источники](GRAPHICS_060.md).

HDR-цвет обрабатывается ACES-подобной кривой и gamma. Monochrome сохраняет нейтральный цвет.

## Настоящий сигнал

Desktop: `MediaPlayer → 512 spectrum bands каждые50ms → AudioEnvelope → shader uniforms`. До сокращения до64 полос сохраняется низкочастотный пик; атака55ms, затухание280ms. В GPU отправляются32 сгруппированные полосы, bass/mid/treble и спектральная энергия. Это не измерение физического SPL/LUFS или точного BPM.

Android/iOS: собственное PCM-расширение expo-audio → FFT/событие спектра → сглаживание → те же uniforms. Микрофон не используется. При отсутствии/устаревании реального сигнала амплитуды становятся нулевыми. Временная координата отвечает за течение газа и материалов, но не подделывает бас.

В Black Hole бас не меняет масштаб или силуэт. Desktop использует положительное изменение спектра `AudioEnvelope.onset`; Mobile — положительный спектральный поток и атаки баса/RMS с затуханием180ms. На постоянном тоне вспышка затухает, без повторного запуска от часов. Остальные режимы сохраняют реакцию на бас и частоты. Высокие частоты меняют мелкие световые детали. Эффекты клика и поворот камеры от курсора отсутствуют. Фоновая сеть частиц остаётся отдельным отключаемым слоем.

## Ограничение нагрузки

Black Hole теперь использует аналитический наклонный диск и исходные процедурные нити без тяжёлого прохода124 шагов. Общие настройки качества продолжают ограничивать физическое разрешение; у остальных сцен они также меняют число слоёв и частиц.

Desktop: LOW/MEDIUM/HIGH — линейное разрешение50%/72%/100%, длинная сторона не более1100px. Телефон дополнительно учитывает PixelRatio: длинная физическая сторона GL-поверхности не более400/640/900px. Это предотвращает умножение тяжёлого фрагментного прохода на плотность экрана. Пользовательский FPS15–60, reduced motion, отключение эффектов и остановка при потере активности сохраняются.

При отсутствии OpenGL3.3 Desktop явно показывает спектральный fallback; он не выдаётся за восемь кинематографических сцен. Проверить его можно с `-Dauralis.graphics.software=true`. На телефоне ошибка GPU отображается прямо в панели. Стабильность60FPS и расход батареи на физическом телефоне без device QA не заявляются.

Текущие кадры и проверки: [CLASSIC_BLACK_HOLE.md](CLASSIC_BLACK_HOLE.md).

Официальные API: [LWJGL](https://www.lwjgl.org/guide), [GLFW](https://www.glfw.org/docs/latest/window_guide.html), [Expo58 GLView](https://docs.expo.dev/versions/v58.0.0/sdk/gl-view/), [PixelRatio](https://reactnative.dev/docs/pixelratio).
