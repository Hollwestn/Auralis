# Улучшенный режим

## Включение и эквалайзер

1. Настройки → «Улучшенный режим». В навигации появляются «Аудиостудия» и «Эквалайзер».
2. Запустите трек, откройте эквалайзер. Перемещение полосы меняет реальный `AudioEqualizer` текущего MediaPlayer. Для сравнения используйте флажок «Эквалайзер включён».
3. Выберите готовый профиль или нажмите «Сохранить профиль». Полосы сохраняются локально. Сильный подъём полос может дать цифровую перегрузку; отдельного realtime preamp пока нет.
4. Скорость на странице EQ управляет JavaFX и меняет тональность. Независимый pitch/time stretch — в студии при экспорте.

## Замена фрагмента

1. В медиатеке нажмите правой кнопкой на реальный трек → «Открыть в аудиостудии». Или запустите его и откройте студию слева.
2. Дождитесь «Предпрослушивание готово». Волна строится по PCM результату рендера.
3. Выделите область мышью либо введите «От, сек» и «До, сек». Для примера при песне длиннее 30 секунд укажите 10 и 20.
4. Нажмите «Заменить файлом», выберите свой аудиофайл. Он целиком встанет вместо 10–20 секунд. Новый результат может иметь другую длительность.
5. Для отмены используйте «↶ Отменить», для повтора «↷ Повторить». Оригинал остаётся на месте.
6. Для точного монтажа сначала работайте с исходной шкалой без speed/crossfade. Поля диапазона относятся к монтажной шкале до этих преобразований.

## Остальные операции

«Обрезать» оставляет выбранный диапазон. «Удалить диапазон» удаляет его. «Вставить файл» вставляет перед началом выделения. «Копировать сюда» и «Переместить сюда» используют поле «Вставить в, сек». Усиление указывается в dB и применяется к выделенному диапазону. Отрицательное значение уменьшает громкость.

В блоке параметров установите Time Stretch (0.5–2), Pitch Shift (-12…12 полутонов), Fade In/Out, Crossfade между clips, выберите эффекты и нажмите «Применить параметры». Реальный PCM рендер производится заново в фоне. Предпрослушивание включает применённые эффекты.

## Сохранение версии

- «Сохранить проект» создаёт `.auralis.json` с монтажными решениями и путями исходников. Его можно открыть снова; для переноса нужны исходные файлы.
- «Экспорт аудио» создаёт WAV, FLAC или MP3. Выберите новое имя, например `song-my-version.flac`. Экспорт поверх исходника запрещён движком.
- Чтобы добавить версию в медиатеку, импортируйте полученный файл обычной кнопкой добавления музыки.
- Чтобы вернуться к оригиналу, откройте исходный трек в медиатеке. Отключение Advanced скрывает инструменты; сохранённые проекты и настройки остаются.

Эта версия не является многодорожечной DAW. Нет realtime parametric EQ, stem separation, автоматического BPM/ключа, mobile DSP parity. Перечень незавершённых функций — `ROADMAP.md`.
