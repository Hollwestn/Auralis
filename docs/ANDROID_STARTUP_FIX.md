# Исправление запуска и звука Android — 0.6.1

На подключённом Samsung Galaxy S21 (SM-G991B) через ADB определён **Android 15**. Вылет после заставки воспроизведён в установленной 0.6.0, причина подтверждена журналом и DEX именно этой сборки. Очистка кэша такой дефект не исправляет.

## Что исправлено

1. Ранее R8 удалял `GLContext.flush()`, который EXGL вызывает через JNI. Это было частично исправлено в 0.6.0.
2. В реальном APK 0.6.0 дополнительно отсутствовал конструктор `GLView(Context, AppContext)`. Expo создаёт этот TextureView через reflection, и стандартное правило для ExpoView его не защищало. Журнал выдавал `Didn't find a correct constructor for class td1`. В плагине prebuild сохранены класс GLView и конструкторы Expo View. Готовый minified APK проверяется на публичные исполняемые `flush()` и конструктор GLView. Фоновый GL также не создаётся до входа в аккаунт, поверхности ожидают ненулевого размера.
3. Проверка настоящего воспроизведения выявила `The source buffer is this buffer`: аудиодвижок передаёт пустой буфер при инициализации/сливе, а PCM-процессор пытался скопировать его в тот же общий буфер. Теперь пустой ввод игнорируется без потери ожидающего вывода. Регрессионный тест сначала воспроизвёл ошибку, после исправления проходят все три нативных PCM-теста.

## Что проверено на телефоне

Финальный release **0.6.1 / versionCode 10** установлен поверх предыдущего с тем же сертификатом. На S21 проверены запуск, вход в отдельный тестовый аккаунт, серверная музыка через нативный ExoPlayer, пауза, восемь GPU-сцен и настройки скорости. Музыкальные вспышки измерены при обоих ползунках на нуле: неподвижная сцена реагирует на реальный PCM, без имитации музыки таймером. Подробности: [мобильный отчёт](MOBILE_TEST_REPORT.md).

A55 к компьютеру не подключался, отдельного подтверждения для него нет. Временный тестовый аккаунт удалён; на S21 оставлен экран входа.

## Установка

1. Используйте новый `release/android/Auralis-Android-Test.apk`, **0.6.1, code10**. Контрольные суммы — `release/SHA256SUMS.txt`.
2. Откройте APK на телефоне и установите обновление поверх прежнего Auralis. Подпись сохранена, удаление приложения не требуется. На подключённом S21 обновление уже установлено.
3. Откройте приложение: после заставки должен появиться вход. Укажите адрес своего сервера и аккаунт.
4. Для разных сетей настройте домен и HTTPS по [SERVER_INTERNET_GUIDE.md](SERVER_INTERNET_GUIDE.md). USB-проброс использовался только для проверки и не заменяет постоянный сервер.

Установка с компьютера:

```powershell
& .\.runtime\android-sdk\platform-tools\adb.exe devices -l
& .\.runtime\android-sdk\platform-tools\adb.exe install -r .\release\android\Auralis-Android-Test.apk
& .\.runtime\android-sdk\platform-tools\adb.exe shell am start -n io.auralis.mobile/.MainActivity
```

Если подключено несколько устройств, после `adb.exe` добавьте `-s SERIAL`, взяв SERIAL из `devices -l`. На телефоне разрешите отладку для этого компьютера. Для диагностики возможной другой ошибки сразу после вылета сохраните журнал:

```powershell
& .\.runtime\android-sdk\platform-tools\adb.exe logcat -b crash -d -t 250 > .\android-crash.txt
```

Перед отправкой проверьте содержимое журнала.
