# Auralis Desktop 0.7.1 — удаление песен из медиатеки

В Windows-клиент добавлено удаление отдельных треков из локальной медиатеки.

## Как пользоваться

1. Откройте «Медиатека» и выделите песню.
2. Нажмите **«Удалить из медиатеки»** над таблицей. Также доступны **Delete** на клавиатуре и одноимённый пункт меню правой кнопки мыши.
3. Проверьте название в диалоге и подтвердите удаление. «Отмена» ничего не меняет.

Без выбранной песни кнопка недоступна. Действие удаляет запись из локальной базы, избранного, истории и пользовательских плейлистов; все повторения песни убираются из текущей очереди. Аудиофайл на диске сохраняется, серверная коллекция не удаляется. При повторном сканировании папки песня может появиться снова.

Для удаления только из конкретного плейлиста сохранена отдельная команда «Удалить из плейлиста».

## Воспроизведение

Удаление другого трека сохраняет текущую позицию и нативный плеер. При удалении текущего выбирается следующий доступный трек (или оставшийся соседний в конце очереди), с сохранением состояния игры/паузы. Удаление последнего трека очищает плеер и очередь. Сохранённая позиция обновляется.

## Установка

Закройте Auralis и запустите `release/desktop/Auralis-0.7.1.exe`. Для старых установок соблюдайте [порядок безопасного обновления](WINDOWS_INSTALLATION.md). Переносимая сборка находится в `release/desktop/Auralis/Auralis.exe`.

Изменения относятся к Desktop; мобильная сборка остаётся 0.7.0. Оформление и музыкальные визуализации сохранены.

## Проверка

`mvn -B -pl apps/desktop -am verify`: 45 тестов без ошибок и пропусков. В том числе проверены каскадное удаление ссылок, сохранность байтов исходного файла, сохранение результата после перезапуска базы, удаление повторов из очереди, переход между треками и сохранение паузы.

Сводка UI-проверок, готовых файлов и контрольных сумм: `release/DESKTOP_071_MANIFEST.json`.
