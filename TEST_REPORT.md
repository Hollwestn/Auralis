# Подготовка Linux и магазинов 0.8.0 — 28.10.2026

Linux Ubuntu 24.04 x86_64: 48 тестов, сборка настоящего DEB, установка и запуск окна комплектным runtime прошли в GitHub Actions. Mobile: TypeScript, ESLint, 24 теста, Android prebuild, тестовый arm64 APK 0.8.0/code13 и Android/iOS Hermes export. Подготовлены production-профили, страницы поддержки/конфиденциальности и русский гайд. Магазинные AAB/IPA не подписывались; физический телефон 0.8.0 не проверялся. В аудите toolchain остаются 3 high и 5 low; исправлены node-forge и воспроизводимость XML-парсера. [Подробный отчёт и ограничения](docs/verification/STORE_LINUX_080.md) · [Гайд](docs/RELEASE_GUIDE.md).

# Desktop 0.7.1 — удаление треков, 27.10.2026

Добавлены кнопка «Удалить из медиатеки», пункт контекстного меню и Delete с подтверждением. Исходное аудио сохраняется; очищаются локальные ссылки и очередь.

Готовая переносимая сборка прошла smoke-проверку с комплектными Java/FFmpeg; JAR сверены со сборкой. Установка поверх пользовательского приложения не выполнялась.

Установщик: `release/desktop/Auralis-0.7.1.exe`. Контрольная сумма: `release/DESKTOP_071_MANIFEST.json`. [Использование](docs/UPDATE_071.md). Мобильная версия не менялась.

# Проверка обновления 0.7.0 — 22 октября 2026

Текущие изменения: восстановление обложек Desktop, нативные теги и обложки локальной Mobile-библиотеки, локальные умные подборки, таймер сна с плавным затуханием. Стили, темы и исходники графических сцен сохранены.

- Maven verify: **60 тестов**, ошибок и пропусков нет (audio-core 11, Desktop 31, server 18). Первые запуски внутри Windows-песочницы блокировали атомарное перемещение временных файлов; полный запуск вне неё прошёл.
- Desktop: **49 проверок UI** на изолированной библиотеке, включая настоящие обложки, подборку, включение/отмену таймера, темы, скорость графики, аудиоплеер, эквалайзер и монтаж; GPU NVIDIA RTX 3050.
- Mobile: TypeScript и ESLint прошли; **19 Node-тестов** и **3 нативных PCM-теста** прошли. Android Release APK 0.7.0/code12 собран, подпись и 16 KiB alignment проверены.
- iOS Hermes export прошёл; Swift/CocoaPods, подпись, установка и поведение на iPhone **не проверены**. В Windows нет Xcode.
- ADB сейчас не обнаруживает подключённого телефона. Android 0.7.0 **не устанавливался и не проверялся на физическом устройстве**. Импорт встроенных изображений, миграция старой Mobile-библиотеки, фон/блокировка и фактическое затухание нового таймера остаются задачами проверки на устройстве. Прежние проверки S21 относятся к старым версиям.

Установщики и SHA-256: `release/LOCAL_070_MANIFEST.json`. [Что изменилось и как пользоваться](docs/UPDATE_070.md).

## Исторические результаты предыдущих версий

# Актуальный мобильный выпуск 0.6.2

Добавлен самостоятельный режим без сервера и регистрации: вход «Продолжить без аккаунта», системный выбор файлов, постоянные внутренние копии, локальные плейлисты, избранное, история, поиск и волна. Исходники не отправляют локальные треки на сервер.

Проверено: TypeScript, ESLint, 17 Node-тестов, 3 нативных PCM-теста, Android/iOS Hermes export, сборка настоящего APK 0.6.2 / code11, подпись v2 и 16KiB alignment. Сверены 36 входных файлов и 11 файлов source map готового APK. APK установлен на S21; в сохранённом UI-снимке виден новый вход без аккаунта.

Полный сценарий локального импорта/воспроизведения на физическом телефоне **не завершён**: проверка разрешений диагностической команды остановлена лимитом использования. Это ограничение проверки, а не подтверждение работоспособности всего нового режима. Его следует проверить перед стабильным выпуском. [Инструкция](docs/MOBILE_OFFLINE_GUIDE.md).

Windows остаётся на 0.6.1. Далее сохранён предыдущий отчёт: его результаты нативного телефона относятся к серверному режиму 0.6.1, не к новой локальной библиотеке 0.6.2.
