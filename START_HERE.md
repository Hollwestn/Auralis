# Начните здесь: Auralis — обновление 22.10.2026

Linux и магазины приложений: [руководство 0.8.0](docs/RELEASE_GUIDE.md). Поддержка: auralishelp@mail.ru.

Это рабочее обновление существующей платформы; полный объём исходного технического задания описан отдельно в ROADMAP.md. Сначала прочитайте `TEST_REPORT.md`: там отделены выполненные проверки от неподтверждённых возможностей. В `ROADMAP.md` перечислены отсутствующие функции. Музыка в поставку не включена.

**Локальное обновление 0.7.0: сервер не обязателен.** После заставки нажмите «Продолжить без аккаунта», затем «Добавить музыку с телефона». Импортированные файлы, плейлисты и настройки хранятся на устройстве. [Пошаговая инструкция](docs/MOBILE_OFFLINE_GUIDE.md). Для сборок 0.7.0 с обложками и таймером см. [описание обновления](docs/UPDATE_070.md).

Если нужен только локальный плеер Windows, достаточно шагов 1, 6, 10–16. Сервер и телефон можно подключить позже.

Если Auralis 0.1 уже установлен, сначала закройте его и выполните `./release/desktop/Safe-Update.ps1` из новой папки проекта. Этот скрипт переносит медиатеку и создаёт резервную копию до открытия установщика. Новая папка данных — `%LOCALAPPDATA%\AuralisData`, программа устанавливается отдельно в `AuralisApp`. Подробный порядок: `docs/WINDOWS_INSTALLATION.md`.
Новая процедурная Black Hole и включение 4K: [BLACK_HOLE_4K.md](docs/BLACK_HOLE_4K.md). Размер сцены сохранён; на телефоне используется адаптивное разрешение.


Выпуск **0.6.1**: независимая скорость графики без музыки и с музыкой, новая иконка, исправление запуска и воспроизведения Android. [Настройка скорости](docs/GRAPHICS_SPEED_AND_ICON.md). [Графика и настройка](docs/GRAPHICS_060.md). Исправление мгновенного вылета Android и порядок установки: [ANDROID_STARTUP_FIX.md](docs/ANDROID_STARTUP_FIX.md).

## 1. Что скачать

Готовые файлы находятся в папке проекта: Windows `release/desktop/Auralis-Setup.exe`, MSI `release/desktop/Auralis-0.6.1.msi`, portable `release/desktop/Auralis/Auralis.exe`; Android `release/android/Auralis-Android-0.7.0-Preview.apk`. Android APK автономный, arm64, Android7+, с тестовой подписью и поддержкой локального HTTP. iOS IPA на Windows не собран. Подробные результаты — TEST_REPORT.md, контрольные суммы — release/SHA256SUMS.txt.

## 2. Какие программы нужны

Для готового Desktop дополнительные Java/Maven не нужны. Для сборки исходников установите JDK25, Maven3.9+, FFmpeg/FFprobe, WiX3. Для сервера в контейнерах — Docker Desktop (Linux containers). Для Android исходников — Node24, JDK17/21, Android Studio/SDK по `docs/ANDROID_INSTALLATION.md`. Для iOS — Mac/Xcode по `docs/IOS_INSTALLATION.md`.

Откройте PowerShell в папке проекта и выполните `.\scripts\check-system.ps1`. Ожидается список `[OK]` и отсутствующих компонентов; устанавливайте только необходимые выбранному сценарию. Если команда не найдена после установки, откройте новую PowerShell и проверьте PATH. Не меняйте глобальную ExecutionPolicy ради запуска; при блокировке корпоративной политикой используйте разрешённую консоль/обратитесь к администратору.

Для устройств в разных сетях используйте [полную инструкцию VPS + домен + HTTPS](docs/SERVER_INTERNET_GUIDE.md) и готовый `release/Auralis-Server-Internet.zip`. Общая Wi-Fi-сеть для этого сценария не нужна.

## 3. Подготовка сервера

Для быстрого запуска готового сервера без Maven выполните:

```powershell
.\release\server\start-dev.ps1
```

Для временного подключения телефона в той же Wi-Fi-сети:

```powershell
.\release\server\start-dev.ps1 -Lan -Port 8080
```

Нужна Java25; база H2 и музыка сохраняются рядом с готовым JAR в `release/server/data`. Остановка — Ctrl+C. Проверка — `Invoke-RestMethod http://127.0.0.1:8080/api/v1/health`. На телефоне используйте частный IP компьютера и тестовый Android APK с разрешённым локальным HTTP. Настройка HTTPS/PostgreSQL для постоянной работы описана отдельно.

Для сборки сервера из исходников на ПК без Docker:

```powershell
mvn -B -pl backend/server -am package "-Dmaven.repo.local=$env:USERPROFILE/.m2/repository"
```

Ожидается `BUILD SUCCESS` и JAR в `backend/server/target`. Для постоянного сервера: скопируйте `infrastructure/.env.example` в `infrastructure/.env`, задайте собственный пароль PostgreSQL. Полная настройка VPS/HTTPS и восстановления — `docs/SERVER_SETUP.md`. Если Maven не запускается, проверьте шаг2.

## 4. Запуск базы

В dev-профиле H2 создаётся автоматически на следующем шаге. Это локальный режим проверки. PostgreSQL запускается Compose:

```powershell
.\scripts\start-server.ps1
docker compose -f infrastructure/compose.yaml ps
```

Ожидаются db/api в состоянии running/healthy. Скрипт запускает оба сервиса; отдельно запускать backend в этом варианте не нужно. При ошибке подключения смотрите `docker compose -f infrastructure/compose.yaml logs --tail 100 db api`. Не удаляйте volumes для исправления конфигурации.

## 5. Запуск backend

Для dev-варианта из шага3:

```powershell
java -jar backend/server/target/auralis-server-0.1.0-SNAPSHOT.jar --spring.profiles.active=dev
```

Оставьте окно открытым. Во второй PowerShell выполните `Invoke-RestMethod http://127.0.0.1:8080/api/v1/health`. Ожидается status `ok`. Если порт занят, остановите предыдущий сервер или задайте `--server.port=8081` и измените адрес в клиентах. Для Docker этот шаг сводится к проверке health после шага4.

## 6. Установка Desktop

Запустите `release/desktop/Auralis-Setup.exe`, пройдите мастер, откройте ярлык. Ожидается окно Auralis и предложение выбрать тему/режим. Можно запустить portable `Auralis.exe` из полного каталога portable вместе с app/runtime; переносить один EXE отдельно нельзя. Инструкция удаления, обновления и сборки — `docs/WINDOWS_INSTALLATION.md`.

## 7. Установка Android

Скопируйте `release/android/Auralis-Android-0.7.0-Preview.apk` на телефон Android7 или новее с arm64-процессором, откройте файл и разрешите установку выбранному файловому менеджеру. После установки откройте Auralis: Metro и Expo Go не нужны. Это тестовая подпись; APK для магазина требует вашего release-ключа. Инструкция собственной сборки и диагностика — `docs/ANDROID_INSTALLATION.md`. Серверный режим 0.6.1 проверен по USB на Samsung Galaxy S21, Android 15. APK 0.6.2 установлен, полная проверка нового локального режима пока не завершена; A55 отдельно не проверялся.

## 8. Подключение телефона

На телефоне укажите HTTPS URL собственного сервера без `/api/v1`. Для определения локального IP на ПК выполните `ipconfig` и найдите IPv4 Wi-Fi-адаптера. Для временного LAN dev сервера телефон и ПК должны находиться в одной Wi-Fi сети; укажите IP ПК, не `localhost`. Dev процесс Java потребует `--server.address=0.0.0.0`, Windows Firewall — разрешённого порта частной сети. Для постоянного доступа используйте Caddy/домен из Server guide. Проверка: откройте `/api/v1/health` по тому же адресу в браузере телефона. Если не открывается, проблема в сети/сервере, а не в музыкальном клиенте.

## 9. Создание аккаунта

Desktop → Настройки → «Открыть серверную коллекцию». Заполните URL, email, пароль (не меньше10 символов), имя; включите создание аккаунта и подключитесь. На телефоне войдите тем же аккаунтом. Ожидается пустой личный серверный каталог. Для локальной медиатеки этот шаг не нужен. При HTTP409 email уже занят: выключите регистрацию и войдите; при401 проверьте пароль. Токены и пароль никому не отправляйте.

## 10. Добавление музыки

Для локального ПК выберите папку в мастере/медиатеке либо отдельные файлы «+ Добавить музыку». Дождитесь окончания фонового сканирования; появятся реальные теги/обложки. Файлы не перемещаются и не отправляются в сеть.

Для телефона нужен серверный каталог. Явно загрузите разрешённый файл через серверный экран Desktop/API; для папки настройте разрешённый import root по Server guide. Не путайте локальный импорт и загрузку серверу. Ожидается серверный track ID в `/tracks` и этот трек на телефоне. При ошибке декодирования проверьте файл FFprobe; при413 уменьшите файл (серверный лимит300МБ).

## 11. Плейлист

Нажмите «+» у «Плейлисты», введите имя. В медиатеке контекстное меню трека → «В плейлист» → ваш плейлист. Откройте его слева, дважды нажмите трек или «Слушать». Перетащите строки для порядка; экспорт M3U8 сохраняет пути. Ожидается сохранение после перезапуска. Пустой плейлист означает, что треки ещё не добавлены. Подробности — `docs/MUSIC_LIBRARY_GUIDE.md`.

## 12. Моя волна

Добавьте несколько треков с artist/genre тегами. Настройки → предпочтения → сохраните жанры/исполнителей. Добавьте любимые треки. Откройте «Моя волна», выберите режим и «Начать слушать»/«Показать подборку». Ожидается очередь из доступной вашей музыки и объяснения. Никакой доступ к подписным сервисам не требуется. При пустом результате проверьте каталог, дизлайки, исключённых исполнителей; Favorites требует избранного. Серверный воспроизводимый API пример — `docs/MY_WAVE_GUIDE.md`.

## 13. Улучшенный режим

Настройки → «Улучшенный режим». Ожидаются новые пункты Студия и Эквалайзер. Отключение скрывает инструменты, проекты остаются. Если пункты не видны, проверьте флажок и прокрутку навигации.

## 14. Эквалайзер

Начните воспроизведение и откройте EQ. Измените полосу/профиль, сравните включённый и выключенный EQ. Нажмите «Сохранить профиль» для своего набора. Ожидается реальное изменение обработки MediaPlayer. Если звука нет, проверьте volume/mute Windows. Это десятиполосный EQ, параметрический режим и отдельный preamp в0.1 отсутствуют.

## 15. Замена фрагмента

Контекстное меню трека → Студия. Дождитесь waveform, задайте диапазон (например10…20сек для достаточно длинной песни), нажмите «Заменить файлом» и выберите свою вставку. Дождитесь нового рендера, предпрослушайте; отмена — кнопкой Undo. Ожидается новая монтажная версия с сохранным оригиналом. Ошибка диапазона требует исправления чисел. Подробный процесс и эффекты — `docs/ADVANCED_MODE_GUIDE.md`.

## 16. Сохранение версии

«Сохранить проект» сохраняет JSON и ссылки на исходники. «Экспорт аудио» создаёт WAV/FLAC/MP3 под новым именем. Импортируйте результат в медиатеку. Ожидается отдельный воспроизводимый файл; исходник не перезаписывается. При запрете перезаписи выберите другое имя, при ошибке FFmpeg проверьте clips/длительности/доступ к диску.

## 17. Синхронизация

Войдите единым аккаунтом. Трек должен существовать в его серверном каталоге. На Desktop в серверном экране явно скачайте/запустите трек, затем отправьте позицию/коллекции соответствующей кнопкой. На телефоне загрузите состояние синхронизации и продолжите. Для обратного переноса используйте Desktop «Продолжить с телефона». Ожидается тот же серверный track ID и positionSeconds. Автоматического копирования личной музыки нет. Локальный файл без серверной копии недоступен другому устройству; конфликт409 требует перечитать актуальную версию.

## 18. Обновление приложения

Закройте Desktop, сохраните копию `%LOCALAPPDATA%/AuralisData` и музыкальных папок, запустите новый установщик. Android обновляется APK с тем же applicationId и тем же ключом подписи. Смена ключа не позволяет обновить приложение поверх старого. Автообновление пока не реализовано.

## 19. Обновление сервера

Сделайте backup PostgreSQL и музыки по Server guide, остановите сервисы без удаления volumes, соберите новый JAR, выполните Compose up с rebuild. Миграции Flyway применяются при запуске. Ожидается health ok и сохранный каталог. При ошибке миграции остановитесь, сохраните логи, восстановите согласованную резервную копию по инструкции; не очищайте БД.

## 20. Типичные ошибки

Начните с `docs/TROUBLESHOOTING.md`. При сетевой ошибке сначала проверьте health; при аудио — путь/кодек/FFprobe; при Android — build log и native permissions. `TEST_REPORT.md` показывает, что проверено в данном окружении. Для сообщения об ошибке нужны версия, точные шаги и текст ошибки, без паролей/токенов.

## 21. Оформление и визуализации

Настройки → карточка темы: Obsidian Yellow, Monochrome, Crimson Noir, Deep Violet, Arctic Silver; ниже сохранены Jade, Amber, Azure. Главная → «Атмосфера»: восемь разных музыкальных форм. Параметры качества, FPS, интенсивности и отключения эффектов — в настройках. Точный порядок и диагностика: [VISUALIZATIONS_GUIDE.md](docs/VISUALIZATIONS_GUIDE.md). Полный список проверок и ограничений: [TEST_REPORT.md](TEST_REPORT.md).
