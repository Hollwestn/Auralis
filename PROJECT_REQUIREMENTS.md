## 1. РОЛЬ И ЗАДАЧА

Ты — Senior Software Architect, Senior Java Developer, JavaFX Engineer, Audio DSP Engineer, Backend Developer, Recommendation Systems Engineer, Mobile Developer, UI/UX Designer и QA Engineer.

# 3. ОБЩАЯ КОНЦЕПЦИЯ

Проект представляет собой музыкальную экосистему из трёх частей:

### Desktop

Полноценное приложение на Java для Windows.

Возможности:
- Локальная музыка.
- Серверная музыка.
- Плейлисты.
- Исполнители и альбомы.
- Поиск.
- История.
- Персональные рекомендации.
- «Моя волна».
- Улучшенный режим.
- Редактор аудио.
- Эквалайзер.
- Синхронизация с телефоном.

### Mobile

Отдельное приложение для Android и iOS.

Оно должно поддерживать:
- Воспроизведение.
- Плейлисты.
- Библиотеку.
- Поиск.
- «Мою волну».
- Историю.
- Синхронизацию.
- Офлайн-режим.

### Server

Собственный музыкальный сервер.

Его задачи:
- Хранение каталога.
- Потоковое воспроизведение.
- Учётные записи.

# 8. МОЯ ВОЛНА — ПЕРСОНАЛЬНАЯ МУЗЫКА

Создай собственный рекомендательный движок.

Функция должна формировать практически непрерывную очередь подходящих композиций из доступного музыкального каталога.

Это самостоятельная реализация идеи персональной музыкальной волны, а не копия закрытых алгоритмов других сервисов.

## Сигналы рекомендаций

Учитывай:
- Лайки.
- Дизлайки.
- Избранное.
- Любимых исполнителей.
- Жанры.
- Историю прослушивания.
- Продолжительность прослушивания.
- Частоту повторов.
- Пропуски.
- Музыкальные характеристики, если они доступны.

Не считай каждый пропуск однозначным дизлайком.

## Режимы волны

- My Wave.
- Discovery.
- Favorites.
- Focus.
- Energy.
- Night.
- Relax.
- Familiar.

## Управление рекомендациями

Добавь действия:
- Нравится.
- Не нравится.
- Больше такого.
- Меньше такого.
- Не рекомендовать исполнителя.
- Сохранить композицию.

## Первая версия алгоритма

Используй content-based filtering.

Начни с:
- Жанров.
- Исполнителей.
- Метаданных.
- Истории.
- Пользовательских реакций.
- Штрафов за повторы.
- Баланса знакомой и новой музыки.

Предусмотри объяснимость рекомендаций.

Не выдавай случайный shuffle за интеллектуальную систему.

## Будущее развитие

Архитектура должна позволять добавить:
- Collaborative filtering.
- Audio embeddings.
- Анализ BPM.
- Анализ энергии.
- Анализ настроения.
- Гибридное ранжирование.
- ML-модели.

Не используй обязательные платные AI API для первой версии.

## Cold Start

Для новых пользователей реализуй:
- Выбор жанров.
- Выбор исполнителей.
- Импорт библиотеки.
- Первоначальные подборки.
- Постепенную адаптацию рекомендаций.

- Обрезка.
