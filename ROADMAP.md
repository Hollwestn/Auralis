# Состояние и дальнейшие этапы

Обновление 18.10.2026 продолжает существующий проект. Фактические результаты сборок, нативных тестов и аппаратные ограничения перечислены в `TEST_REPORT.md`.

| Область | Реализовано | Оставшаяся работа |
|---|---|---|
| Интерфейс | Утверждённая новая композиция Desktop/Mobile, 5 новых тем + 3 прежние, собственные векторные иконки, постоянный плеер, адаптация компоновки | UX-проверка на большой личной коллекции, дополнительные DPI/разрешения/доступность |
| Визуализации | 8 разных режимов, настоящий спектр, 3D Desktop/GLSL Mobile, касания/курсор, фон, интенсивность, качество/FPS, полное отключение | Измерения энергопотребления и GPU на слабых устройствах, длительные аппаратные сеансы |
| Desktop | Локальный импорт, поиск, группы альбомов/исполнителей, плейлисты/M3U8/обложки, queue/history/favorites, EQ, LRC | Smart playlists, автоматический watcher папок, отдельный оконный mini-player, мультимедийные клавиши Windows |
| Studio | Настоящий FFmpeg-монтаж, waveform, undo/redo, сохранение проекта, предпрослушивание, WAV24/FLAC/MP3 | Масштабируемая многодорожечная шкала, realtime parametric EQ/preamp/stereo-width, профили DSP на трек |
| Backend | Auth, личный каталог, Range streaming, REST/OpenAPI, versioned sync, идемпотентная история, слияние избранного | PostgreSQL/Docker нагрузочные проверки, полноценная распределённая транзакция коллекций и tombstones удалений, мониторинг/backup restore в реальном развёртывании |
| Wave | Content ranking, предпочтения/реакции/история, причины выбора, режимы и пополнение очереди | Оценка релевантности на большой коллекции, BPM/key/embeddings/collaborative filtering |
| Mobile | Настоящий нативный плеер/очередь, серверный каталог, поиск, плейлисты, история, лайки, офлайн, волна, sync, GL/PCM-анализ | Проверки на физических Android/iOS: фон, lockscreen, Bluetooth, interruptions, батарея; мобильные EQ/монтаж не реализованы |
| Release | Воспроизводимые scripts, runtime/FFmpeg в Windows, проверенный автономный Android arm64 APK с тестовой подписью, русские руководства | Коммерческая подпись Windows/Android, чистая Windows VM, macOS/Xcode/TestFlight, автообновление |

Поставляемая медиатека пуста. Тесты используют только созданные локально сигналы; фиктивные треки, случайный сигнал вместо аудио, коммерческий каталог и обязательные платные AI API не используются.
